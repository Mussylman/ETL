# Идеи и улучшения

## Интерфейс
- Drag-and-drop для порядка колонок
- SQL preview в реальном времени при добавлении колонки
- Подсказки: 1С-поля которые есть в большинстве источников
- Визуальная схема связей: parent → child, source → union → target

## Функционал
- Импорт/экспорт конфигурации (JSON)
- Копирование регистра (clone)
- Diff: что изменилось с последней загрузки
- Тестовый запуск: SELECT TOP 10 с трансформациями

## Архитектура
- Union и Target — скрытая механика (не отдельные вкладки)
- Единственный source of truth — Column Builder
- Source Detail — read-only маппинги

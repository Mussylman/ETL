Patch · Rebuild · Reconciliation

PATCH

Точечно обновляет изменившиеся документы: документ и все его строки заменяются из 1С.

REBUILD

Полностью пересобирает конкретную месячную партицию из 1С и публикует её целиком после сверки.

RECONCILIATION · SWEEP

Сверяет каждый месяц 1С ↔ ClickHouse по независимому отпечатку и пересобирает разошедшиеся.

Как завести новый факт / регистр

Без миграции: конфиг — данными control plane. Каждая команда без --apply выполняется и откатывается (dry-run), повтор ничего не меняет.

{% for x in c.commands.new_fact %}{{ cli(x) }}{% endfor %}

ch_config — конфиг публикации

sync / scaffold / export

etl_meta.ch_sync + ch_sync_columns по JSON-спецификации; черновик — из цели регистра.

scope

Область реестра id: sequence + doc_key_scope. Удаление — только пустой области.

group show / set / add / order

ch_sync_group, состав и порядок (priority).

Защиты

Одна транзакция под advisory-блокировкой; действующее — только с --allow-live; соединение — только явно.

ch_promote — shadow → production

gates

Схема = конфиг, engine/partition/order, дубли, not_zero, сироты, recorder → id = doc_key; закрытые партиции строго 1:1 с 1С, открытые (--open-window N) — shadow ⊆ источника.

перенос

REPLACE PARTITION … FROM shadow — жёсткие ссылки, без перезагрузки, id те же; конфиг — одной транзакцией.

rollback

Выключает боевую группу и конфиги; таблицы, doc_key, история не трогаются.

discard

Удаляет неиспользуемые боевые таблицы и отзывает их права.

# Год 4025 исправляется на 2025 в датах 1С

## Проблема
1С MSSQL хранит даты со сдвигом +2000 лет. Период `2025-03-15` записан как `4025-03-15`.

## Решение
Файл: `dags/core/transform/dates.py`

Функция `fix_year`:
- `4025-03-15 10:30:00` → `2025-03-15 10:30:00`
- Работает с datetime и строками
- Вычитает 2000 из года

## Применение
- Transform type: `fix_year`
- Поля: `_Period`, `_Date_Time`, `_NumberPrefix`
- В MSSQL тип: `datetime`

## В ETL Config App
Автоматически ставится для всех колонок с MSSQL типом `datetime`:
```python
("datetime", None): ("timestamp", "fix_year")
```

# Платформа для дата-аналитиков компании

## Кто пользователи
Дата-аналитики, которые уже умеют писать запросы в 1С и знают структуру данных. Им нужен инструмент для настройки ETL без написания Python-кода.

## Что делают
- Настраивают выгрузку данных из 1С ERP (MSSQL) в PostgreSQL
- Строят аналитические витрины (sales, sales_positions и т.д.)
- Объединяют несколько типов документов в одну таблицу (UNION)
- Настраивают инкрементальную загрузку

## Что знают
- Структуру 1С (регистры, документы, табличные части)
- SQL на базовом уровне
- Какие поля нужны для аналитики

## Что НЕ знают / не хотят делать
- Писать Python-код
- Настраивать Airflow DAGи
- Разбираться в binary-конвертации
- Вручную создавать таблицы в PostgreSQL

## UX-принцип
Конфигуратор должен быть как Airtable/Supabase — визуальный, понятный, 3 шага:
1. Выбрать источники (Discover)
2. Определить колонки (Column Builder)
3. Всё остальное — автоматика

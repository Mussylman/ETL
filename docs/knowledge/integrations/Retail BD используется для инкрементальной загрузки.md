# Retail BD используется для инкрементальной загрузки

## Назначение
1С разработчики создали API который записывает изменённые документы в базу `bd_retail`.
ETL платформа обращается к bd_retail напрямую для обнаружения изменений.

## Подключение
```
PostgreSQL: 10.10.1.142:5432/bd_retail (airflow_admin)
```

## Ключевые таблицы
- `sales` — 885К записей, есть `document_uid` (UUID) и `updated_at`
- `sale_positions` — строки продаж, связь через sale_id

## Режим инкрементальной загрузки
1. Найти записи где `updated_at > last_load_time`
2. Взять их `document_uid` (UUID документа)
3. Конвертировать UUID → binary(16) для запроса в 1С MSSQL
4. Загрузить только изменённые записи
5. UPSERT в target таблицу

## В конфигураторе
Поля регистра:
- `retail_table` = "sales"
- `retail_uid_column` = "document_uid"

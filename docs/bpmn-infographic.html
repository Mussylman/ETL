⚙ Три режима загрузки ETL Core

🔄
Full Period
Полная перезагрузка по диапазону дат. INSERT ONLY. Для первичной настройки.
▲
Incremental
Каждые 5 мин. DataChecker находит изменения через bd_retail. UPSERT.
✅
Consistency
Каждые 4 часа. Проверка целостности: нет ли пропущенных записей.

🔀 Трансформации Автоматически

MSSQL типPostgreSQL типФункция
binary(16) → uuid binary_to_uuid
binary(4) → integer binary_to_int
binary(1) → boolean binary_to_bool
datetime → timestamp fix_year (4025→2025)
nvarchar → varchar cast
numeric → decimal cast
+ binary_fields_raw (JSONB) — оригинальные бинарные значения для аудита

🗃 Схема etl_meta Source of Truth

R
registers — реестр: имя, код, режим загрузки по умолчанию
S
register_sources — таблицы MSSQL (header / detail / standalone)
M
column_mappings — source_col → target_col + transform
U
source_unions + members — UNION нескольких источников
T
register_targets — PostgreSQL таблица, upsert_keys, pre_load_sql
H
load_history — аудит каждой загрузки

H

D

J

L
